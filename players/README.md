# Player photos

Put one photo per player in this folder, named exactly like the player's name on the site:

- `Dana.jpg`, `Noa.png`, `Omer.webp` ...
- Allowed types: `.jpg`, `.jpeg`, `.png`, `.webp`
- Capitals must match the name on the site (`Dana.jpg`, not `DANA.jpg`); an all-lowercase file name (`dana.jpg`) also works.
- Square-ish photos look best; they are cropped to fill the card. Keep each under about 500 KB so the TV loads fast.

If a player has no photo, the TV and the remote show the first letter of their name instead.
